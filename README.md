# Qadam Astana

Smart City MVP for choosing a single place or event in Astana within time,
location, and budget constraints. Shared foundation: S00 (Sabyrzhan).
Frontend: React/Vite/TypeScript, owned by Damir; it is not generated by S00.
Backend: FastAPI/Pydantic. Target database: Supabase Postgres/PostGIS/pgvector.

## Windows PowerShell: run from the repository root

Python 3.12+ is required. These commands do not require activating a virtual
environment or changing the PowerShell execution policy.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements.txt
if (-not (Test-Path backend/.env)) { Copy-Item backend/.env.example backend/.env }
.\.venv\Scripts\python.exe -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000
```

Copy the example only when `backend/.env` does not already exist; never overwrite
local credentials. In another PowerShell window, also at the repository root:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/health
```

Expected JSON: `{"status":"ok"}`. Health works without an `.env` file, API keys,
or a database. Interactive API documentation: <http://127.0.0.1:8000/docs>.
Only health is implemented in S00; search endpoints are contracts for later stages.

## Configuration

Backend settings always read `backend/.env` relative to `settings.py`, regardless
of the current working directory. Runtime environment variables take precedence.
See `backend/.env.example`. Secrets stay on the server.

Damir's frontend uses `VITE_API_BASE_URL=/api` and optionally the public,
domain-restricted `VITE_TWOGIS_MAP_KEY`. The Vite development proxy should forward
`/api` to `http://127.0.0.1:8000`. Never expose `DATABASE_URL`, `OPENAI_API_KEY`,
or the server `TWOGIS_API_KEY` through a `VITE_` variable.

Real `.env` files are excluded from Git and Docker build context.

## Verification (repository root)

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
.\.venv\Scripts\python.exe -m compileall -q backend/app scripts
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check backend scripts
.\.venv\Scripts\python.exe -m ruff format --check backend scripts
.\.venv\Scripts\python.exe scripts/export_contracts.py --check
.\.venv\Scripts\python.exe scripts/preflight.py --check all
```

Preflight checks are independent and read-only for the database. Responses and
embedding probes use synthetic text and may incur a small API charge. Missing
credentials or connectivity are recorded as `not_run`, not as a successful test.
The handoff records actual checks and any blockers.
