## D02 repository handoff and data flow

See `contracts/api-v1.md` for copyable construction and async call examples.
Import `DatabasePool` from backend.app.database and `PostgresPOIRepository` from
backend.app.repository. Use backend Settings; never expose DATABASE_URL in D01.
Always close the pool after an import process finishes.

`records -> Source/POIRecord validation -> permissions/test gate -> stable
identity locks -> stored observation comparison -> transactional POI, sources,
facts writes -> inserted/updated/rejected counts -> import_runs -> commit`.

- Identity is `(primary provider, external_id)`, stored as source/source_item_id.
  Existing canonical IDs are retained even when ingestion proposes another ID.
- First valid batch identity wins. Later duplicates are duplicate_in_batch.
  Original input indexes and input processing order are retained. Locks are
  acquired in sorted order to prevent inverse-order deadlocks.
- Primary timestamps use provenance matching BOTH primary_source_id and
  external_id. Use the oldest match; any matching null/no match is unknown.
  Known stored time rejects older/unknown incoming time; equal time updates.
  Unknown stored time accepts known or unknown incoming data. Retrieval time
  never substitutes for observation time.
- Counts sum to input size. Per-record validation/rights/stale/ID conflicts are
  rejections. Infrastructure failure rolls back all accepted rows and raises
  DatabaseUnavailable; a separate best-effort failed import audit is attempted.
- Partial imports do not deactivate or delete absent POIs. No fixture or
  production import is triggered by application startup.
- Source text is separate from generated explanations, with a SHA-256 hash.
  Embeddings store model, dimensions=1536 and matching text hash. Changed text
  or revoked indexing rights removes the old embedding. Storage-only sources
  can be stored but cannot receive embeddings or enter text/geo search indexes;
  2GIS records are rejected.
- Geo search uses WGS84 geography, a meter radius, stable nearest-first order
  and bounded limits. It does not calculate a route, time fit or recommendation.
