   tests validate base meaning keys, placeholders, actual locale plural
   categories, Kazakh characters, keyboard submission, html.lang, KZT and the
   Astana midnight boundary. These are quality checks, not new UI features.

   heading; grid children can shrink. A 290-character synthetic source name
   previously expanded a 320px page to 2483px, then 2806px when selected. Both
   states were reproduced and corrected without truncating the source name.

   frontend. The old pending D04 response shape incorrectly rejected published
   1.3 replies, including valid unavailable replies. The shared generated
   contract, references and uncertainty govern the adapter and its tests.
   Shared backend/contracts are unchanged. The checker/README describe the
   actual shared schema and distinguish the historical development shape.
